On 0.3.1 or older? The launcher offers this update: press **UPDATE TO 0.4.0** next to PLAY.

## New

- **Real upscaling** (by kuraeow, #50; asked for in #45): Display -> **Upscaling**: FSR 1,
  FSR 3.1, FSR 4 or DLSS, with **Quality**, Balanced, Performance or Ultra Performance. The game
  draws below your resolution and each frame is upscaled before the HUD and menus are drawn, so
  they stay sharp. **DLAA / Native AA** (no upscaling) works as before. Upscaling saves GPU time:
  it helps most at 4K and on weaker graphics cards, less where the processor limits the frame
  rate. Moving characters can smear below Quality.
  The **Low** preset is now 1080p with FSR 1 Performance (sharp HUD).

## Fixed

- **Freezes before some cutscenes** (#52): about 1.6 s on PC, up to 33 s on the Steam Deck.
  Gone: the same cutscene went from a 1650 ms frame to about 200 ms.
- **Drake's Fortune: enemy grenade launchers no longer blow up on Drake** (#6). From the second
  shot on, the grenade exploded right in front of him; every shot now flies to its target.
- **Uncharted 3 could freeze for good with Multithreaded rendering on** (#51). Fixed; to be safe,
  Multithreaded rendering stays off for Uncharted 3 until players confirm it.
- **Drake's Fortune: Infinite ammo** (Cheats tab) now keeps the magazine full too.

## Install (new players)

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (your dump, for example
   `CUSA02344`, with `eboot.bin` and `sce_sys`). Update 1.02 is recommended: next to the game
   folder named like it plus `-patch`, chosen in Advanced -> GAME UPDATE, or copied into the
   game folder.
3. Pick a game and a preset and press **PLAY**.
