The first release of the **Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).
*Drake's Fortune*, *Among Thieves* and *Drake's Deception* run natively on Windows: the games' own
x86-64 code runs on the PC, a runtime supplies the PS4 system libraries, and a Vulkan renderer
(built on shadPS4's) executes the PS4 GPU work.

> **No game files are included.** You need your own dump of the Collection (CUSA02344). This
> project is not affiliated with Sony, Naughty Dog or Bluepoint Games.

## Install

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`, often called `uroot`).
3. **Recommended: update 1.02.** Extract it next to the game folder, named like it plus `-patch`
   (for example `CUSA02344-patch`). The launcher's Advanced tab shows the version in use.
4. Pick a game and a preset and press **PLAY**. The first start of each game compiles shaders:
   expect a slow first load and some stutter until the cache has filled.

**Requirements:** Windows 10/11 64-bit, a GPU with Vulkan 1.3 and a current driver, 16 GB RAM, a
fast CPU (the PS4's GPU command processing runs on the CPU).

## What works

- All three games from one launcher, with per-game settings and quality presets (720p to 4K;
  Drake's Fortune up to 1620p, upscaled with FSR 1).
- Saves, audio (music, speech, effects), cutscene movies, the Collection menu.
- Keyboard and mouse with mouse look and remappable controls per game; DualSense, DualShock 4 and
  Xbox controllers.
- In-game menu: **Insert** or **R3 + L2** (display mode, frame-rate limit, sharpening, overlay).

## Fixed for this release (highlights)

- **Uncharted 2:** crashes at treasure pickups and in the Treasures screen; Nate floating or
  invisible; a crash with multithreaded rendering; the frame rate falling over minutes of play;
  stalls in heavy scenes.
- **Faster heavy scenes:** every preset now queues 2 frames, so the CPU prepares the next frame
  while the GPU draws. Uncharted 2's museum at 1080p: 44-47 FPS before, 56-59 now.
- **Drake's Fortune:** bullet impacts, bullet holes and blood; cutscene movie colours at 1620p;
  dark interiors (fire and flashlight light).
- **All games:** grey/black ground and unlit characters; missing sound effects; frame-rate limit
  capped at 120 (faster breaks the games' movement); launcher and in-game menu settings stay in
  step.

Full list: [CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Recommended settings

- Start with the **Medium** preset (1080p, as on PS4); High and Ultra need a fast GPU.
- **Multithreaded rendering:** leave it **off**, or in Uncharted 2 use it only with
  **Frames queued 1** (see below).
- **Drake's Fortune at 4K:** turn on **Upscale with FSR 1** (it renders at most 1620p).
- **Frame-rate limit:** 60 is the PS4's; 120 is experimental.

## Known issues

- **Some heavy Uncharted 2 scenes still dip below 60 FPS** with short hitches (frames of 35-50 ms
  a few times a second). Work on them continues.
- **Multithreaded rendering with Frames queued 2** can end Uncharted 2 with the game assert
  `m_gfxEopTick` after a few minutes.
- Uncharted 3 has had less play testing than the other two games.
- Report problems with the log from the launcher's **Advanced → Open log folder**.

Automatic updates from the launcher are coming with the next version.
