**Uncharted: The Nathan Drake Collection** PC port by **BilalReloaded**
([YouTube](https://www.youtube.com/@BilalReloaded/videos), [GitHub](https://github.com/bc160201983)).

## New: the launcher updates itself

From this version on, the launcher checks for a new release when it starts and shows
**UPDATE TO x.y.z** next to PLAY when there is one. It asks first, downloads the package, checks it
against the SHA-256 that GitHub publishes for the release, installs it and starts again.

- Your **saves, settings and shader cache are kept**.
- If anything goes wrong (for example the game is still running), every replaced file is put back
  and the installed version keeps working.
- **Advanced** tab: turn the check off, or press **Check for updates**.

**Coming from 0.1.0:** download this version once by hand (0.1.0 has no update button yet), and
copy the `analysis` folder from your old folder into the new one: it holds your saves, settings
and shader cache.

## Install

1. Download **Uncharted-windows.zip** below and extract it anywhere.
2. Start **Uncharted Launcher.exe** and select your game folder (the dumped `CUSA02344` folder with
   `eboot.bin` and `sce_sys`, often called `uroot`).
3. **Recommended: update 1.02.** Extract it next to the game folder, named like it plus `-patch`
   (for example `CUSA02344-patch`).
4. Pick a game and a preset and press **PLAY**. The first start of each game compiles shaders.

> **No game files are included.** You need your own dump of the Collection (CUSA02344). This
> project is not affiliated with Sony, Naughty Dog or Bluepoint Games.

Everything in [0.1.0](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/releases/tag/v0.1.0)
still applies (what works, recommended settings). Full list of changes:
[CHANGELOG.md](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port/blob/main/CHANGELOG.md).

## Known issues

- **Some heavy Uncharted 2 scenes still dip below 60 FPS** with short hitches (frames of 35-50 ms
  a few times a second). Work on them continues.
- **Multithreaded rendering with Frames queued 2** can end Uncharted 2 with the game assert
  `m_gfxEopTick` after a few minutes: leave multithreaded rendering off.
- Report problems with the log from the launcher's **Advanced → Open log folder**.
